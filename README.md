# От ГЕМ до агенти

Практически курс от 12 лекции, започва от основите на машинното обучение и езиковите модели и стига до изграждането на AI агенти. Курсът е изграден основно около Jupyter notebooks с допълнителни слайдове.

## Теми

1. Въведение в AI и ML
2. От линейни модели до невронни мрежи
3. Токенизация
4. Механизми на внимание (Attention)
5. Transformer архитектура и дълъг контекст
6. Базови модели и данни за предобучение
7. Емерджентни способности при мащаб
8. Подравняване и RLHF
9. Локални ГЕМ
10. Промптинг и модели за разсъждение
11. Халюцинации и RAG
12. AI агенти и инструменти

## Лекция 1: Въведение в AI и ML

Първата лекция покрива основните понятия в машинното обучение — дефиниция на задачи, етикети, признаци, обучаващи и тестови данни, видове обучение (supervised, unsupervised, reinforcement learning), пренастройване и недонастройване, метрики. Включва и практическа работа с n-gram езикови модели и демо с GPT-2 като контраст.

## Инсталация

Проектът изисква Python >= 3.12 и използва [uv](https://docs.astral.sh/uv/) за управление на зависимости.

```bash
# Инсталиране на uv (ако нямате)
curl -LsSf https://astral.sh/uv/install.sh | sh

# Клониране на проекта
git clone <repo-url>
cd llms-with-applications-private

# Създаване на виртуална среда и инсталиране на зависимости
uv sync

# Стартиране на Jupyter
uv run jupyter notebook
```

### Основни зависимости

- `torch` — PyTorch
- `transformers` — Hugging Face Transformers (GPT-2 и други модели)
- `jupyter` / `notebook` — Jupyter notebooks
- `matplotlib` / `seaborn` — визуализации
- `pandas` — работа с данни
- `scikit-learn` — ML утилити
