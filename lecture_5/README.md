# Предобучение на nanoGPT върху корпус на Иван Вазов

Скриптът `pretrain_decoder.py` тренира малък GPT модел (decoder-only трансформер) върху текстове на Иван Вазов. Всички резултати се логват автоматично в MLflow.

---

## Бързо стартиране

```bash
# С настройките по подразбиране (препоръчително за начало)
uv run python lecture_5/pretrain_decoder.py

# По-голям модел, повече епохи
uv run python lecture_5/pretrain_decoder.py --epochs 5 --n_layer 6 --n_head 6 --n_embd 384
```

Скриптът трябва да се изпълнява от **корена на проекта**, не от папката на лекцията.

---

## Какво да очакваме

**Токенизатор** — при първото стартиране се тренира BPE токенизатор и се записва в `checkpoints/tokenizer.json`. При следващи стартирания се зарежда от файла (освен ако не се подаде `--retrain_tokenizer`).

**Тренировъчен цикъл** — всеки `--eval_interval` стъпки скриптът изчислява train/val loss и го отпечатва. Очаквайте нещо подобно:

```
step   20 | train loss 7.2311 | val loss 7.3102 | lr 3.00e-04
step   40 | train loss 6.8754 | val loss 6.9201 | lr 2.85e-04
...
Epoch 1/8 done in 142.3s | avg train loss 6.6120 | 18450 tok/s
```

**Loss стойности** — в началото загубата е около 6–8. След 3–5 епохи с настройките по подразбиране трябва да падне около 5.

**Снимки (checkpoints)** — записват се автоматично след епохи 1, 25%, 50%, 75% и 100% от тренировката, в `checkpoints/checkpoint_epoch_N.pt`. Финалният модел се записва в `checkpoints/decoder_vazov.pt`.

**Генерация** — след всяка snapshot епоха моделът генерира 150 токена с промпт `"Вазов"`. Текстът се логва в MLflow. В края на тренировката се генерират 200 токена и се отпечатват в конзолата.

## Изходни файлове

```
lecture_5/checkpoints/

  checkpoint_epoch_N.pt     # Снимки по време на тренировката

  decoder_loss.json         # История на загубата (train/val по стъпки)
```

## Аргументи от командния ред

### Данни

| Аргумент | По подразбиране | Описание |
|----------|-----------------|----------|
| `--corpus` | `data/ivan_vazov.txt` | Път до текстовия корпус |
| `--out_dir` | `lectures/lecture_05/checkpoints` | Папка за изходни файлове |

### Токенизатор

| Аргумент | По подразбиране | Описание |
|----------|-----------------|----------|
| `--vocab_size` | `4096` | Размер на речника (брой BPE токени) |
| `--retrain_tokenizer` | `False` (флаг) | Принудително претрениране на токенизатора дори ако вече съществува |

### Архитектура на модела

| Аргумент | По подразбиране | Описание |
|----------|-----------------|----------|
| `--n_layer` | `6` | Брой трансформерни блокове |
| `--n_head` | `6` | Брой attention heads |
| `--n_embd` | `384` | Размер на embedding пространството |
| `--block_size` | `256` | Максимална дължина на контекста (токени) |

### Тренировка

| Аргумент | По подразбиране | Описание |
|----------|-----------------|----------|
| `--epochs` | `8` | Брой епохи |
| `--batch_size` | `64` | Брой примери в един batch |
| `--lr` | `3e-4` | Максимална скорост на учене (learning rate) |
| `--min_lr` | `3e-5` | Минимален LR в края на cosine decay |
| `--warmup_steps` | `0` | Брой стъпки за загряване. `0` = автоматично (5% от общите стъпки) |
| `--eval_interval` | `20` | Оценка на val loss на всеки N стъпки |
| `--log_interval` | `10` | Отпечатване на step loss на всеки N стъпки |

## MLflow — проследяване на експериментите

### Стартиране на MLflow UI

```bash
uv run mlflow ui
```

Отваря се на [http://localhost:5000](http://localhost:5000). Всички run-ове се намират в експеримент `vazov-gpt`.

### Какво се логва

**Параметри** (веднъж при старт):

- Архитектура: `n_layer`, `n_head`, `n_embd`, `vocab_size`, `block_size`
- Тренировка: `epochs`, `batch_size`, `lr`, `min_lr`, `warmup_steps`, `total_steps`
- Брой параметри: `n_params`

**Метрики** (по стъпки):

- `train_loss` / `val_loss` — загуба на train/val множествата
- `train_perplexity` / `val_perplexity` — перплексност
- `val_train_gap` — разлика между val и train loss (индикатор за overfitting)
- `lr` — текущата скорост на учене
- `grad_norm` — норма на градиентите (всяка стъпка)
- `tokens_per_sec` — скорост на обработка (по епохи)

**Артефакти**:

- `samples/epoch_N.txt` — генериран текст след всяка snapshot епоха

### Сравняване на run-ове

В MLflow UI можете да изберете няколко run-а и да ги сравните графично — полезно за сравнение на различни размери модели или learning rate стойности.

## Примери

```bash
# Малък бърз модел за тест
uv run python lecture_05/pretrain_decoder.py \
  --n_layer 2 --n_head 2 --n_embd 128 --epochs 2

# По-голям модел с по-бавен lr decay
uv run python lecture_05/pretrain_decoder.py \
  --n_layer 8 --n_head 8 --n_embd 512 --epochs 10 --lr 1e-4 --min_lr 1e-5

# Препретрениране на токенизатора с по-голям речник
uv run python lecture_05/pretrain_decoder.py \
  --vocab_size 8192 --retrain_tokenizer
```
